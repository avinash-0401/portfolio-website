# Avinash Yadav - Personal Portfolio

This repository contains the source code for my personal portfolio website, featuring sections for my projects, experience, skills, and contact details.

## Features
- **Modern Responsive Design**: Optimized for desktop, tablet, and mobile screens.
- **Typing Animation**: Dynamic sub-headings on the hero section.
- **Pure CSS Transitions**: Beautiful animations, sticky header, and custom CSS-only mobile drawer menu.
- **Form Integration**: Fully functioning contact form with Formspree and Web3Forms support.
- **Performance Optimized**: Zero external dependency blocks, using lightweight inline SVGs.

## Local Development
To run this project locally, simply clone the repository and open `index.html` in your browser, or run a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

## Hosting
This site is ready to be hosted on platforms like [Vercel](https://vercel.com) or [GitHub Pages](https://pages.github.com).
